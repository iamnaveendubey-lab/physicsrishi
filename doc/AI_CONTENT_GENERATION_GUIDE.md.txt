# PhysicsRishi AI Content Generation Guide
Version: 1.0
Status: Engineering Specification
Owner: Founder + CTO

---

# Purpose

This document defines the standard procedure for generating PhysicsRishi chapters using Artificial Intelligence.

The objective is NOT to generate random educational content.

The objective is to generate premium, exam-oriented, revision-focused content that follows the PhysicsRishi Gold Standard Chapter Specification.

Every generated chapter must be reviewed by a Physics subject expert before publishing.

---

# AI's Role

AI is NOT the teacher.

AI is NOT the author.

AI is a content generation assistant.

The final responsibility of academic correctness always belongs to the PhysicsRishi academic team.

---

# Primary Goal

Generate a chapter that helps a serious JEE/NEET aspirant

• Revise quickly

• Understand deeply

• Practice effectively

• Detect weaknesses

• Improve confidence

The generated chapter must improve exam performance rather than increase reading time.

---

# Content Philosophy

Never generate textbook-style content.

Never copy NCERT.

Never create unnecessarily long explanations.

Every paragraph should help the student score more marks.

Every screen should have only one objective.

# Visual Design Guidelines

Every concept should fit on one screen.

Use bullets instead of paragraphs.

Prefer diagrams over text.

Prefer tables over long explanations.

Highlight formulas.

Highlight exam tricks.

Highlight common mistakes.

# AI Restrictions

Never generate copied copyrighted content.

Never copy directly from NCERT or coaching material.

Never fabricate formulas.

Never invent scientific facts.

Never produce low-quality MCQs.

Never repeat identical examples.

Never exceed the specified content length.
